
# Veteriner Kliniği Randevu ve Hasta Takip Sistemi

## Proje Hakkında
Sakarya Üniversitesi Web Programlama dersi kapsamında
ASP.NET Core MVC kullanılarak geliştirilen veteriner
kliniği yönetim sistemidir.


## Proje Özellikleri
- Kullanıcı ve rol yönetimi
- Evcil hayvan kayıtları
- Veteriner yönetimi
- Hizmet yönetimi
- Randevu oluşturma ve onaylama
- Aşı ve muayene kayıtları
- REST API
- MCP entegrasyonu

## Proje Durumu
Temel proje altyapısı, modeller ve veritabanı oluşturuldu.
